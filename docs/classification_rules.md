# Report Classification Rules

מערכת סיווג הדוחות נועדה לנתב כל קובץ סרוק למנגנון החילוץ (Parser) התואם לו, בהתבסס על הטקסט שחולץ ממנו בשלב ה-OCR.

## לוגיקת הסיווג
הסיווג מתבצע על ידי מחלקת `ReportClassifier` בשיטת **Scoring (ניקוד)**:
1. המערכת מחזיקה רשימות של "מילות מפתח מובהקות" (Markers) עבור כל סוג דוח (מוגדר ב-`config/constants.py`).
2. המערכת סורקת את הטקסט וסופרת כמה מילות מפתח מכל סוג קיימות בו.
3. הדוח מסווג לפי הסוג שקיבל את הניקוד הגבוה ביותר. 
4. במקרה של שוויון באפס (אף מילה לא נמצאה), המערכת תחזיר `UNKNOWN` והקובץ יידחה או יעבור לטיפול ידני, כדי למנוע קריסה בשלבי הפארסינג.
